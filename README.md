# SQL Practice & Query Reference

A continuously growing collection of T-SQL scripts covering fundamentals, data manipulation, aggregation, and joins. New scripts added regularly as a Product Analyst building practical SQL proficiency for data extraction, reporting, and analysis.

---

## 📂 Repository Structure

Files follow the naming convention `SQLQuery<N> <Topic>.sql`, numbered in the order each concept was practiced.

```text
SQL-Practice/
│
├── SQLQuery1 create employee.sql
├── SQLQuery2 Select Queries.sql
├── SQLQuery6 Where Clause.sql
├── SQLQuery16 MAX & Group BY.sql
├── SQLQuery22 Inner Join.sql
└── README.md
```

---

## 🧠 SQL Skills Covered

| Category | Topics |
|---|---|
| **Database Setup** | CREATE DATABASE, CREATE TABLE, Temporary Tables |
| **Data Retrieval** | SELECT, DISTINCT, TOP, ORDER BY |
| **Filtering** | WHERE, AND, OR, NOT, BETWEEN, IN, NULL handling |
| **Data Manipulation (DML)** | INSERT, UPDATE, DELETE |
| **Database Objects** | DROP, TRUNCATE |
| **Aggregations** | COUNT, SUM, AVG, MIN, MAX |
| **Grouping** | GROUP BY, HAVING |
| **Joins** | INNER JOIN |

---

## 💡 Key Learning Outcomes

- Writing readable, well-structured SQL queries
- Understanding relational database design and table relationships
- Applying filtering and aggregation logic to answer business questions
- Differentiating similar concepts (WHERE vs HAVING, DELETE vs TRUNCATE vs DROP)
- Building a foundation for analytical and reporting queries
